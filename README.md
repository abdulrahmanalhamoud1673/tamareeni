# تماريني

تطبيق عربي بسيط لتسجيل تمارين الحديد ومتابعة تطوّرها.

**https://abdulrahmanalhamoud1673.github.io/tamareeni/**

---

## الفكرة

شاشة واحدة: تختار يوم التمرين، تسجّل الوزن والتكرار لكل مجموعة، وتشوف أرقام آخر مرة جنب كل تمرين حتى تعرف إذا تطوّرت.

- جدول جاهز بأربعة أيام: صدر وترايسبس · ظهر · أكتاف وبايسبس · أرجل وبطن
- اسم كل تمرين بالعربي وبالإنجليزي جنب بعض، بنفس التسمية المستخدمة في الجدول الأصلي
- صورة صغيرة جنب كل تمرين — تضغط عليها فتكبر وتوريك وضعية البداية والنهاية
- السوبرست معلَّم كما في جدولك، ومؤقّت الراحة يتخطّى نفسه بين تمريني السوبرست
- كل تمرين يفتح بأرقام آخر مرة معبّاة مسبقاً — تعدّلها بأزرار − و + وتضغط ✓
- تلميح «زِد الوزن» يظهر تلقائياً عند إنجاز كل التكرارات المستهدفة في المرة السابقة
- ملاحظة لكل تمرين (إعداد المقعد، مكان الجهاز، نوع القبضة) تبقى محفوظة
- مؤقّت راحة يبدأ تلقائياً بعد كل مجموعة (المدة قابلة للتعديل)
- زر حذف لكل مجموعة، ولكل تمرين أو يوم كامل في السجل
- قياساتي: بيانات آخر بطاقة InBody جاهزة، رسم بياني للوزن، وخطة غذائية من الذكاء الاصطناعي بأرقامك الحقيقية
- تقرير أسبوعي: أرقامك، شو تطوّر وشو واقف مكانه، وتحليل من المدرب الذكي
- توقّع متى توصل للهدف بناءً على سرعة تطوّرك الفعلية
- حاسبة توزيع أوزان البار لتمارين البار
- مساعد ذكي اختياري: صوّر أي جهاز في النادي واسأل عنه (Gemini المجاني)
- سجل بكل التمارين السابقة
- نسخة احتياطية بملف

بدون حساب، بدون إنترنت، بدون إعلانات. البيانات محفوظة داخل متصفّح جهازك فقط.

## التثبيت على الجوال

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← تثبيت التطبيق
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← إضافة إلى الشاشة الرئيسية

بعدها يفتح كتطبيق مستقل ويعمل بدون إنترنت.

## مصدر الصور

صور التمارين مأخوذة من [free-exercise-db](https://github.com/yuhonas/free-exercise-db) — مجموعة بيانات تمارين
مفتوحة تحت رخصة **Unlicense** (ملكية عامة)، أي أن استخدامها وإعادة توزيعها مسموحان بلا قيود.
الصور مصغّرة إلى عرض ٤٠٠ بكسل ومحفوظة داخل التطبيق في مجلد `img/` ليعمل بدون إنترنت (المجموع ١.١ ميغابايت).

لإعادة تحميلها أو تغيير المطابقة: عدّل `tools/map.json` ثم شغّل `tools/get-images.ps1`.

## تعديل الجدول

الأوزان والتمارين موجودة في أعلى `app.js` داخل `PROGRAM` — كل سطر: اسم التمرين، ثم `[الوزن, التكرار]` لكل مجموعة.

## التشغيل محلياً

```bash
node server.js
```

ثم افتح `http://localhost:5180`
