# تماريني

تطبيق عربي بسيط لتسجيل تمارين الحديد ومتابعة تطوّرها.

**https://abdulrahmanalhamoud1673.github.io/tamareeni/**

---

## الفكرة

شاشة واحدة: تختار يوم التمرين، تسجّل الوزن والتكرار لكل مجموعة، وتشوف أرقام آخر مرة جنب كل تمرين حتى تعرف إذا تطوّرت.

- جدول جاهز بأربعة أيام: صدر وترايسبس · ظهر · أكتاف وبايسبس · أرجل وبطن
- كل تمرين يفتح بأرقام آخر مرة معبّاة مسبقاً — تعدّلها بأزرار − و + وتضغط ✓
- مؤقّت راحة يبدأ تلقائياً بعد كل مجموعة (المدة قابلة للتعديل)
- سجل بكل التمارين السابقة
- نسخة احتياطية بملف

بدون حساب، بدون إنترنت، بدون إعلانات. البيانات محفوظة داخل متصفّح جهازك فقط.

---

## التثبيت على الجوال

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← تثبيت التطبيق
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← إضافة إلى الشاشة الرئيسية

بعدها يفتح كتطبيق مستقل ويعمل بدون إنترنت.

---

## تعديل الجدول

الأوزان والتمارين موجودة في أعلى `app.js` داخل `PROGRAM` — كل سطر: اسم التمرين، ثم `[الوزن, التكرار]` لكل مجموعة.

## التشغيل محلياً

```bash
node server.js
```

ثم افتح `http://localhost:5180`
