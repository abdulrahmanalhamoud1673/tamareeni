# تماريني

تطبيق عربي بسيط لتسجيل تمارين الحديد ومتابعة تطوّرها، ومتابعة القياسات والأكل.

**https://abdulrahmanalhamoud1673.github.io/tamareeni/**

---

## الفكرة

شاشة واحدة: تختار يوم التمرين، تسجّل الوزن والتكرار لكل مجموعة، وتشوف أرقام آخر مرة جنب كل تمرين حتى تعرف إذا تطوّرت.

- جدول جاهز بأربعة أيام، كل يوم بلونه الخاص
- اسم كل تمرين بالعربي وبالإنجليزي، وصورة توضّح الحركة
- كل تمرين يفتح بأرقام آخر مرة معبّاة مسبقاً — تعدّلها بأزرار − و + وتضغط ✓
- تلميح «زِد الوزن» وتنبيه رقم قياسي عند تسجيل وزن أعلى من أي وزن سبق
- مؤقّت راحة يبدأ تلقائياً بعد كل مجموعة، وحاسبة توزيع أوزان البار
- تقرير أسبوعي: أرقامك، شو تطوّر وشو واقف مكانه، وتحليل من المدرب الذكي
- قياساتي: بيانات آخر بطاقة InBody، رسم بياني للوزن، وخطة غذائية بأرقام محددة (سعرات وبروتين وكارب ودهون) من الذكاء الاصطناعي
- الأكل: صوّر أي وجبة والذكاء الاصطناعي يقدّر سعراتها وبروتينها وكاربها ودهونها، مع مجموع يومي يقارن بخطتك الغذائية
- مساعد ذكي اختياري: صوّر أي جهاز في النادي واسأل عنه (Gemini المجاني)

بدون حساب، بدون إنترنت لغير ميزات الذكاء الاصطناعي، بدون إعلانات. البيانات محفوظة داخل متصفّح جهازك فقط.

---

## التثبيت على الجوال

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← تثبيت التطبيق
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← إضافة إلى الشاشة الرئيسية

بعدها يفتح كتطبيق مستقل ويعمل بدون إنترنت (عدا ميزات الذكاء الاصطناعي).

---

## تفعيل المساعد الذكي (مجاني)

من صفحة «اسأل»، الصق مفتاح Gemini المجاني (من aistudio.google.com/apikey) — يتفعّل تلقائياً فور اللصق. نفس المفتاح يشغّل تحليل الأسبوع، خطة الغذاء، وتحليل صور الوجبات.

---

## تعديل الجدول

الأوزان والتمارين موجودة في أعلى `app.js` داخل `PROGRAM` — كل سطر: اسم التمرين، ثم `[الوزن, التكرار]` لكل مجموعة.

## مصدر صور التمارين

من [free-exercise-db](https://github.com/yuhonas/free-exercise-db) تحت رخصة Unlicense (ملكية عامة). لإعادة تحميلها أو تغيير المطابقة: عدّل `tools/map.json` ثم شغّل `tools/get-images.ps1`.

## التشغيل محلياً

```bash
node server.js
```

ثم افتح `http://localhost:5180`
