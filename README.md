# 💪 تماريني — مدرب الحديد

تطبيق عربي لتتبّع تمارين الحديد وتطويرها. يعمل بدون إنترنت، ويُثبَّت على الجوال كتطبيق حقيقي (PWA).

**🔗 التطبيق:** https://abdulrahmanalhamoud1673.github.io/tamareeni/

---

## الميزات

**التسجيل**
- جدول جاهز بـ ٤ أيام: صدر وترايسبس · ظهر · أكتاف وبايسبس · أرجل وبطن
- تسجيل كل مجموعة (وزن × تكرار) بضغطة واحدة، وأزرار كبيرة تناسب الاستخدام داخل النادي
- مؤقّت راحة يبدأ تلقائياً بعد كل مجموعة، مع صوت واهتزاز، وراحة أقصر للسوبرست
- الشاشة تبقى مضاءة أثناء التمرين
- تسجيل بالصوت: "بنش برس ٨٠ ثمانية"

**التطوّر**
- عرض "آخر مرة" أثناء التسجيل لمقارنة فورية
- اقتراح التطوّر التدريجي: متى تزيد الوزن ومتى تزيد التكرار
- رسوم بيانية لتطوّر كل تمرين (أقصى وزن + حجم التدريب)
- حساب أقصى قوة تقديرية (1RM) بمعادلة Epley
- توازن العضلات وتنبيه للعضلة المهملة
- أرقام قياسية شخصية مع احتفال عند كسرها

**المتابعة**
- تقويم شهري وسلسلة التزام
- وزن الجسم والقياسات مع رسم بياني
- صور التقدم مع مقارنة جنباً إلى جنب
- نظام نقاط ومستويات
- نسخ احتياطي واسترجاع بملف

**المدرب الذكي (اختياري)**
يعمل بمفتاح Google Gemini المجاني:
- تحليل التقدّم واقتراح التعديلات
- بدائل لأي تمرين
- تصوير أي جهاز في النادي ← معرفة اسمه وطريقة استخدامه الصحيحة

---

## التثبيت على الجوال

1. افتح الرابط أعلاه من متصفّح الجوال.
2. **أندرويد (Chrome):** القائمة ⋮ ← *تثبيت التطبيق* / *إضافة إلى الشاشة الرئيسية*.
3. **آيفون (Safari):** زر المشاركة ⬆️ ← *إضافة إلى الشاشة الرئيسية*.

بعدها يفتح كتطبيق مستقل ويعمل بدون إنترنت.

---

## الخصوصية

كل البيانات (التمارين، القياسات، الصور) محفوظة داخل متصفّح جهازك فقط — لا يوجد خادم ولا حساب ولا رفع لأي مكان. احفظ نسخة احتياطية من صفحة **السجل** كل فترة.

## التشغيل محلياً

```bash
node server.js
# ثم افتح http://localhost:5180
```

لإعادة توليد الأيقونات: `node make-icons.js`
